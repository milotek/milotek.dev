# Milo's Acronyms

Here's a list of acronyms that me and some of my friends use, as some sort of terrible, unfunny, reoccuring inside joke.

| Acronym          | Phrase                           | Meaning                                                                               |
| ---------------- | -------------------------------- | ------------------------------------------------------------------------------------- |
| **MSC***         | Many Such Cases                  | Used when something that is typical of something occurs.                              |
| **GP**           | Gameplay                         | Derived from video games. Gameplay = actions = things that people do.                 |
| **LGP***         | L Gameplay                       | L / bad / stupid actions.                                                             |
| **UGP**          | Unserious Gameplay               | Unserious / stupid / nonsensical actions.                                             |
| **GAJP**         | Get A Job Please                 | Used when someone does something atypical of an employed person.                      |
| **PPASO**        | Please Put A Shirt On            | Akin to saying "stop acting like an idiot".                                           |
| **DTM(axxing)*** | Doing Too Much (maxxing)         | When someone's being too excitable / doing way more than needed.                      |
| **ZV**           | Zero Value                       | Adjective: unvaluable, rubbish, useless.                                              |
| **NOV**          | Nothing Of Value                 | Adjective: unvaluable, rubbish, useless.                                              |
| **TII***         | Tuff In India / Indonesia        | If something is cool, it's TII :)                                                     |
| **CLife**        | Chud Life / CL Life              | Inferred.                                                                             |
| **CL**           | Changelist                       | [Basically, a git pull request](https://google.github.io/eng-practices/#terminology). |
| **FMCL**         | Fuck My Chud / Chungus / CL Life | Infer from above.                                                                     |

If you're reading this, it's probably because I said one of these in conversation, and you had no idea what I was talking about. I'm sorry.

You should start using these, so then you can be part of the cool kids club.

Except for the ones marked with an asterisk, it is imperative you do not say these aloud. Just use them over text.
